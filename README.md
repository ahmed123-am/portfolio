# بورتفوليو أحمد جلال — React

نسخة React كاملة من الموقع، معمولة بـ React و Vite. فيها عربي/إنجليزي، أقسام التعريف والمهارات، سبعة مشاريع، روبوت SVG كامل بيتابع مؤشر الماوس، ونموذجان للتواصل: البريد وواتساب.

## تشغيل الموقع على جهازك

1. ثبّت Node.js 22.12 أو أحدث.
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal داخل المجلد واكتب:

   ```bash
   npm install
   npm run dev
   ```

4. افتح الرابط المحلي الذي سيظهر في نافذة الأوامر.

لا تفتح `index.html` بالنقر المزدوج بعد التحويل إلى React؛ شغّله بالأوامر السابقة.

## رفعه على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. من المستودع افتح **Settings → Pages** واجعل مصدر النشر **GitHub Actions**.
3. ارفع التغييرات إلى الفرع `main` أو `master`. ملف العمل الموجود في `.github/workflows/deploy.yml` سيبني الموقع وينشره تلقائيًا.
